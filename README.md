# 🛒 NovaCart – E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- 🔍 Product Search
- 🗂️ Category Filter
- 🛍️ Add to Cart
- ❌ Remove from Cart
- 💰 Dynamic Total Price
- 💾 LocalStorage Cart Persistence
- 📱 Responsive UI
- ✅ Demo Checkout
- 🌙 Premium Dark UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API

## 📂 Project Structure

```text
NovaCart/
│── index.html
└── README.md
```

## 🎯 Project Functionalities

- Browse products
- Search products instantly
- Filter products by category
- Add multiple products to cart
- Remove products from cart
- Automatically calculate cart total
- Persist cart data using LocalStorage
- Responsive design for desktop, tablet and mobile

## ▶️ How to Run

1. Download or clone the repository.
2. Open the `NovaCart` folder.
3. Open `index.html` in a browser.
4. For development, you can use VS Code Live Server.
